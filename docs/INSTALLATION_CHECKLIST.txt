WINDOWS - INSTALLATION STEPS
═════════════════════════════════════════════════════════════════════

☐ STEP 1: Verifica Python
  → Premi Windows + S
  → Digita: powershell
  → Apri Windows PowerShell
  → Digita: python --version
  → Premi INVIO
  → Risultato: Python 3.10 o superiore ✅
  → Se errore: Scarica Python da python.org, SEGNA "Add to PATH"

☐ STEP 2: Vai nella cartella AYKO
  → Apri Esplora File (icona cartella)
  → Naviga alla cartella AYKO
  → Premi Shift + Click destro nello spazio vuoto
  → Clicca "Apri finestra PowerShell qui"
  → Vedrai: C:\Users\TuoNome\...\ayko-ai>

☐ STEP 3: Esegui installazione (aspetta 15-30 minuti)
  → Nella finestra PowerShell digita:
     .\install.bat
  → Premi INVIO
  → Guarda i progressi:
     [1/6] Python ✅
     [2/6] Ambiente virtuale ✅
     [3/6] Moduli Python ✅
     [4/6] Vosk model ✅
     [5/6] Ollama (chiede installazione se necessaria)
     [6/6] TinyLlama model ✅
  
  ⚠️  Se durante [5/6] vedi "Ollama not found":
      → Scarica da https://ollama.ai/download
      → Installa il file .exe
      → Clicca il link nella finestra PowerShell
      → Aspetta installazione
      → Riapri PowerShell
      → Riesegui: .\install.bat

☐ STEP 4: Quando vedi "✅ INSTALLAZIONE COMPLETATA"
  → Premi un tasto per chiudere

☐ STEP 5: Avvia AYKO (primo run)
  → Nella stessa cartella premi Shift + Click destro
  → Apri PowerShell
  → Digita: .\venv\Scripts\activate.bat
  → Premi INVIO
  → Vedrai: (venv) C:\Users\...\ayko-ai>
  → Digita: python run.py
  → Premi INVIO
  → Dopo 5-10 secondi si apre la finestra AYKO

☐ STEP 6: Test microphone
  → Nella finestra AYKO clicca "🎤 Start Listening" (blu)
  → La sfera diventa BLU (sta ascoltando)
  → Parla chiaro: "AYKO, apri youtube"
  → Attendi 1-2 secondi
  → Sfera torna VERDE
  → YouTube si apre nel browser
  ✅ SE SUCCEDE: FUNZIONA PERFETTAMENTE!
  ❌ SE NON FUNZIONA: Vedi sezione TROUBLESHOOTING sotto

TROUBLESHOOTING - SE QUALCOSA NON VA
═════════════════════════════════════════════════════════════════════

PROBLEMA: "ModuleNotFoundError" o "import error"
SOLUZIONE:
  → Windows: .\venv\Scripts\activate.bat
  → macOS/Linux: source venv/bin/activate
  → Digita: pip install -r requirements.txt
  → Ripeti: python run.py

PROBLEMA: "Ollama not found" o "model not found"
SOLUZIONE:
  → Windows/macOS: Scarica https://ollama.ai/download
  → Linux: Digita: curl https://ollama.ai/install.sh | sh
  → Riavvia il PC
  → Riesegui install.bat o install.sh

PROBLEMA: AYKO non sente il microfono
SOLUZIONE:
  → Windows: Impostazioni → Privacy → Microfono → ON
  → macOS: Impostazioni → Sicurezza → Microfono → Consenti
  → Linux: Test con: arecord -l
  → Riavvia AYKO: python run.py

PROBLEMA: AYKO si apre ma non risponde ai comandi
SOLUZIONE:
  → Ollama potrebbe ancora scaricare il modello
  → Nel Terminale digita: ollama pull tinyllama
  → Aspetta 10 minuti che finisca
  → Riavvia: python run.py

PROBLEMA: "Python version too old"
SOLUZIONE:
  → Hai Python < 3.10
  → Aggiorna Python a 3.10 o superiore
  → Riesegui install.bat/install.sh

PROBLEMA: Windows dice "not recognized as an internal or external command"
SOLUZIONE:
  → Hai sbagliato a digitare il comando
  → Ricopia esattamente: .\install.bat (con il punto all'inizio)
  → O: python run.py (senza il punto)

PROBLEMA: Spazio disco non basta durante installazione
SOLUZIONE:
  → Cancella file grandi (video, foto vecchie)
  → Svuota Cestino
  → Libera almeno 15 GB
  → Riesegui install.bat/install.sh
