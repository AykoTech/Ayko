# ⚡ JARVIS - QUICK SETUP (Esperti)

```bash
# 1. Setup
python -m venv venv
source venv/bin/activate  # o: .\venv\Scripts\activate.bat (Windows)

# 2. Installa
pip install -r requirements.txt

# 3. Prerequisiti
ollama pull tinyllama  # ~700MB, 5-10 min
# (Opz) Vosk model: scarica da https://alphacephei.com/vosk/models se serve

# 4. Avvia
python run.py
```

**Note:**
- Python 3.10+
- Ollama esterno (ollama.ai)
- PyAudio rimosso (non critico - Vosk usa sounddevice)
- Vosk model facoltativo (viene usato se presente in ./model/)

**Troubleshoot:**
```bash
python check_environment.py  # diagnostica
python test_architecture.py  # valida arch
```
