🔧 EXTENSIBILITY

Add New Tool (< 5 minutes):
  1. Create class in src/core/tools.py
  2. Register in src/core/tool_registry.py
  3. Map intent in src/core/command_parser.py
  4. Done! LLM learns automatically.

Add New Intent (< 1 minute):
  1. Add entry to INTENT_TO_TOOL dict
  2. LLM learns from training

Modify Tool (< 2 minutes):
  1. Edit tool.execute() method
  2. Zero impact on other components
