# AYKO v0.0.01 - Comandi Disponibili

## Come usare AYKO

1. Avvia l'applicazione
2. Clicca "Start Listening" (o usa il tasto `Alt+A`)
3. Pronuncia la wake-word seguita dal comando: **"AYKO, apri youtube"**

---

## Comandi Disponibili

### Aprire applicazioni

"AYKO, apri chrome"
"AYKO, apri vscode"
"AYKO, apri spotify"
"AYKO, apri discord"
"AYKO, apri firefox"


### Chiudere applicazioni

"AYKO, chiudi chrome"
"AYKO, chiudi spotify"
"AYKO, chiudi discord"


### Informazioni di sistema

"AYKO, che ora è"
"AYKO, che giorno è"
"AYKO, uso della CPU"
"AYKO, memoria disponibile"
"AYKO, batteria"


### Volume

"AYKO, volume 80"
"AYKO, volume 50"
"AYKO, volume 0"


### Ricerca web

"AYKO, cerca python tutorial"
"AYKO, cerca meteo Milano"
"AYKO, cerca notizie oggi"


### Aprire URL

"AYKO, apri youtube.com"
"AYKO, apri github.com"
"AYKO, apri google.com"


### Storico comandi

"AYKO, cosa ho fatto"
"AYKO, ultimi comandi"
"AYKO, statistiche comandi"
"AYKO, cancella storico"


### Suggerimenti

"AYKO, cosa posso dire"
"AYKO, aiuto comandi"


### Contesto schermo

"AYKO, cosa c'è sullo schermo"
"AYKO, che app è aperta"
