📋 WHAT IS AYKO?
────────────────────────────────────────────────────────────────────────────

AYKO is a voice-controlled desktop AI coworker that:
  ✓ Understands natural language commands
  ✓ Executes system actions (open apps, search web, get info)
  ✓ Runs completely locally (no cloud)
  ✓ Works on Windows, macOS, and Linux
  ✓ Has a beautiful 3D animated interface

Inspired by Marvel's AYKO but completely open-source and free.


🎯 GET STARTED (2 MINUTES)
────────────────────────────────────────────────────────────────────────────

Choose your OS:

  WINDOWS:
    1. Open PowerShell here
    2. Run: .\install.bat
    3. Run: python run.py

  macOS / LINUX:
    1. Open Terminal here
    2. Run: chmod +x install.sh
    3. Run: ./install.sh
    4. Run: source venv/bin/activate
    5. Run: python run.py

❓ FAQ
────────────────────────────────────────────────────────────────────────────

Q: What if setup fails?
A: Run: python check_environment.py
   Check what's missing and install it.

Q: Microphone doesn't work?
A: Windows: Settings > Privacy > Microphone > Allow
   macOS: System Prefs > Security > Microphone

Q: How do I add custom commands?
A: Read DEVELOPMENT.md (5 min guide included)

Q: Can I change the wake-word from "AYKO"?
A: Yes! Settings panel in the app.

Q: Does it need internet?
A: Runs completely offline.
   Only needs internet for web search commands.

Q: Can I run it on i3 with 8GB RAM?
A: Yes! That's the minimum spec. Tested and working.
