FLUSSO OPERATIVO
================

1. User parla: "JARVIS, apri youtube"
                    ↓
2. AudioInputManager cattura e riconosce wake-word
                    ↓
3. CommandParser estrae intent: ("open_app", {"app": "youtube"})
                    ↓
4. SystemController esegue: subprocess.Popen(["youtube"])
                    ↓
5. TTSEngine parla: "Ho aperto YouTube"
                    ↓
6. UI aggiorna (sfera 3D pulsa, log mostra comando)


DIPENDENZE ESTERNE
==================

Sistema Operativo:
  - Python 3.10+
  - Ollama (LLM backend)
  - Microfono + Altoparlanti

Python Packages (auto-installate):
  - PyQt6 (UI framework)
  - PyQtWebEngine (per sfera 3D)
  - vosk (speech-to-text)
  - pyttsx3 (text-to-speech)
  - sounddevice (audio)
  - requests (HTTP)
  - psutil (system info)
  - pyautogui (automation)

Modelli Ollama (auto-scaricati):
  - tinyllama:latest (1.1B - velocissimo)
  - Opzionale: mistral (7B - migliore qualità)

PERFORMANCE TARGETS
===================

Hardware: Intel i3 13gen + 8GB RAM

Latency Goals:
  - Wake-word detection: ~100ms
  - STT processing: ~500ms
  - Command execution: ~50ms
  - TTS generation: ~300ms
  - Total: ~1 second end-to-end

Memory Usage:
  - Base app: ~200MB
  - TinyLlama loaded: +700MB
  - Total with overhead: ~1GB (leaves 7GB free)

CPU Usage:
  - Idle: <5%
  - During command: ~40-60%
  - Full load capacity: can handle 2-3 commands/sec


DEVELOPMENT QUICKSTART
=======================

1. Clone: git clone https://github.com/edoardopensi/jarvis-ai.git

2. Setup:
   - Windows: .\install.bat
   - macOS/Linux: ./install.sh

3. Run:
   - source venv/bin/activate (or venv\Scripts\activate on Windows)
   - python src/main.py

4. Extend:
   - Add commands in src/core/command_parser.py
   - Add handlers in src/utils/system_control.py
   - Customize sfera in assets/sphere.html

5. Build:
   - python setup.py bdist_wheel
   - Distribuzione in dist/


TROUBLESHOOTING MATRIX
======================

Problema                  → Soluzione
─────────────────────────────────────────────────
Ollama non found          → ollama --version (install from ollama.ai)
Microfono non riconosce   → Check privacy permissions
Sfera 3D è lenta          → Riduci particles in sphere.html
LLM timeout               → Aumenta timeout in llm_engine.py
Memory leak               → Monitor con Task Manager/Activity Monitor
Setup fallisce            → Controlla Python version (3.10+)
Import errors             → Verifica venv attivo
